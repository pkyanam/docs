# about me

i'm a software / computer engineer based in ashburn, virginia. i graduated from virginia tech in may 2023 with a b.s. in computer engineering, concentrating in controls, robotics and autonomy.

i like the layers — bytes on the wire, transistors on the board, and agents on top. most of what i build sits somewhere across embedded systems, emulation, and ai agent infrastructure.

## what i do now

i work as an it contractor at **harrington process solutions (hipco)**, building internal applications and working on ai initiatives across a stack of .net, react, coldfusion, and sql — leaning on tools like claude, cursor, and devin to move faster.

outside of work, i build under **belweave**, my own independent ai r&d lab. it isn't a registered company — it's the umbrella i put my projects under: [trifecta](/projects/trifecta), a cross-platform coding agent platform; [brainbase + graphbrain](/projects/brainbase), a knowledge-graph api for agents; and a rotating set of experiments.

## what drives me

i learn by building. whether it's a rust cli, an arduino library that drives a roomba, a gba emulator written from the cpu up, or an mcp server that wakes a ps5 — every project is an excuse to go a layer deeper into a technology and ship something real.
